## Studio 0.2.0

Quản lý storyboard và thư viện ảnh/video theo dự án, lưu lựa chọn clip, nhập voice và ghép phim local. Ảnh AI, ảnh → video Muse, AI viết kịch bản và TTS API chưa mở. Xem [hướng dẫn Studio](docs/studio-user-guide.md) và [huỷ/xoá tác vụ](docs/queue-cancel-guide.md).
